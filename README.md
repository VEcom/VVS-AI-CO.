# VVS-AI-CO

**VVS (반도체 협력사 AI 문서제작)** 를 **헤르메스(Hermes) 에이전트** 위에 재구축하는 저장소.

이 저장소는 `betplay-mvp` 의 검증된 로직(절대선·block·persona·rubric·Ops)을
헤르메스 에이전트 런타임 위로 이식하여, 반도체 협력사 대상 AI 문서제작 시스템을
영구 보존 가능한 형태로 재구성하는 것을 목표로 한다.

## 핵심 원칙

- **절대선(絶對線) = 헌법.** 다른 어떤 기능보다 먼저, 그리고 항상 강제된다.
- **영구 보존.** 모든 핵심 구조와 로직은 VVS-AI-CO 커밋으로 보존한다.

## 디렉터리 구조

```
VVS-AI-CO/
├── skills/            # 헤르메스 스킬 (에이전트 능력 단위)
│   ├── absolute-line/ # 절대선 — 헌법 (B-1 최우선)
│   ├── block/         # block 로직
│   ├── persona/       # persona 로직
│   └── rubric/        # rubric (평가/채점 기준)
├── tools/             # 도구 (외부 호출/유틸)
├── plugins/
│   └── memory/        # 메모리 플러그인
├── ops/               # 운영 로직 (Ops)
└── tests/             # 테스트
```

## 재구축 로드맵

| 단계 | 내용 | 상태 |
|------|------|------|
| **B-0** | 구조 생성 · 헤르메스 설치 · betplay 로직 20개 복사 · 영구 보존 커밋 | 진행 중 (부분 완료) |
| **B-1** | 절대선 3강제점 — **최우선** (헌법) | 대기 |

> **B-0 이후 B-1(절대선 3강제점)이 최우선이다. 절대선은 헌법이며 다른 기능보다 먼저 구현한다.**

자세한 착수 현황과 차단 요인은 [`ops/B-0-STATUS.md`](ops/B-0-STATUS.md) 참조.
