# 리조트피플 모바일 프로모션 리플렛 플랫폼 구축 — 제안서

> Kmong 의뢰 #226253 응답 · 작성일 2026-06-02
> 레퍼런스 분석: `service.butfit.io/lead/mapo` (모바일 리드수집 랜딩)

---

## 0. 제안 한 줄 요약

종이 리플렛을 **링크 하나로 공유되는 모바일 웹 리플렛**으로 전환합니다. 9개 지점을
하나의 플랫폼에서 운영하되 공통요소는 본사가 일괄 통제하고 지점별 내용만 차별화하며,
리드(문의)는 **본사/지점 2단계 권한**으로 분리 관리합니다. 본 제안서와 함께 **실제
동작하는 프로토타입**(랜딩 + 관리자 컨셉 + DB 스키마)을 동봉했습니다.

## 1. 의뢰인 질문에 대한 직접 답변

### Q1. 예상 제작 일정 및 비용

```
총 4주 (2026-06-05 ~ 2026-06-30) / 7,000,000원 (예산 내)

1주차  설계·디자인 확정    : 정보구조, 9지점 데이터모델, 디자인시안(레퍼런스 기반), 관리자 와이어프레임
2주차  프론트엔드 구축      : 모바일 반응형 랜딩(전 섹션), 지점 라우팅, 리드폼, 링크공유/UTM, OG카드
3주차  백엔드·관리자 구축   : NodeJS API + MySQL, 본사/지점 2단계 관리자, 리드 대시보드/CSV, 인센티브 추적
4주차  콘텐츠 입력·QA·배포  : 9개 지점 실콘텐츠 입력, 크로스브라우저/디바이스 QA, 도메인·HTTPS 배포, 인수인계

지급: 계약(40%) / 2주차 프론트 검수(30%) / 최종 배포(30%) 권장
```

### Q2. 관리자 페이지 제공 범위

```
[본사 관리자] — 전체 수정·편집 권한
 · 브랜드 공통요소 편집 : 브랜드 소개, 콘텐츠 카테고리, 인센티브 정책, 디자인
 · 전 지점 콘텐츠 편집  : 지점 소개, 강사·트레이너, 시간표, 월간 이벤트, 마일스톤
 · 전 지점 리드 열람·검색·상태관리·CSV 내보내기
 · 지점 계정 생성/관리

[지점 관리자] — 자사 지점 한정
 · 자사 지점 리드 "조회만" (편집 불가, 타 지점 열람 불가 — 서버에서 권한 강제)
 · (옵션 협의) 자사 지점 리드 상태 변경 / CSV 내보내기

* 권한 분리는 화면 숨김이 아니라 백엔드 API 레벨에서 강제합니다(동봉 server/app.js 참조).
```

### Q3. 텍스트·이미지 직접 수정 가능 여부

```
가능합니다. 추가 비용 없음.
 · 관리자 페이지의 입력 폼에서 텍스트(소개·시간표·이벤트 문구 등)와
   이미지(지점 사진·트레이너 사진 등)를 비개발자도 직접 교체할 수 있도록 제공합니다.
 · 본사는 전 지점, 지점 관리자는(허용 시) 자사 콘텐츠를 수정합니다.
 · 코드 배포 없이 즉시 반영됩니다.
```

### Q4. 인터랙션(동작/기능) 수정 시 추가 비용

```
구분해서 안내드립니다.
 · 콘텐츠/문구/이미지/시간표/이벤트 변경        → 무료 (관리자에서 상시)
 · 기존 기능의 단순 옵션 조정                    → 검수기간 내 무료
 · 새로운 화면·기능·연동(예: 결제, 카카오 알림톡,
   외부 CRM 연동, 신규 인터랙션 추가)            → 별도 견적
 · 납품 후 하자보수(버그)                        → 1개월 무상

추가 기능은 작업 전 항상 사전 견적·합의 후 진행하며, 임의 청구는 없습니다.
```

### Q5. 지점 확장 시 추가 비용

```
구조적으로 무료에 가깝게 설계합니다.
 · 본 플랫폼은 "지점 = 데이터 1건" 구조입니다(동봉 schema.sql).
   10번째, 11번째 지점은 관리자에서 지점 추가 → 콘텐츠 입력만 하면 됩니다. → 추가 개발비 0원
 · 단, 지점마다 "구조 자체가 다른" 특수 레이아웃이 필요하면 그 부분만 별도 견적.
 · 콘텐츠 대량 입력 대행이 필요하면 건당 소액(협의)으로 지원 가능.
```

## 2. 구현 범위 (의뢰서 요구사항 매핑)

| 의뢰 요구사항 | 구현 방식 | 프로토타입 확인 |
|---|---|---|
| 모바일 반응형 웹페이지 | 480px 기준 모바일 퍼스트, 전 기기 대응 | `index.html` |
| 브랜드 소개 / 지점 소개 | 공통(본사) + 지점별 섹션 분리 | 랜딩 상단 섹션 |
| 콘텐츠 / 강사·트레이너 / 시간표 / 월간 이벤트 | 데이터 기반 섹션 렌더링 | 랜딩 중단 섹션 |
| 리드(문의) 등록 + 인센티브 | 폼 + 동의 + 인센티브 안내 + 완료 화면 | 랜딩 하단 폼 |
| 링크로 프로모션 확인 | `?branch=ID` 라우팅 + OG카드 + Web Share/복사 | 공유 버튼 |
| 9개 지점(공통 동일, 지점별 차별화) | 1 코드베이스 · 9 데이터 | 상단 지점 셀렉터 |
| 관리자 2단계(본사/지점) | role 기반 권한 + 서버 강제 | `admin.html` |
| HTML/CSS/JS/NodeJS/MySQL | 프론트 정적 + Express + MySQL8 | `server/` |

레퍼런스(butfit)에서 차용한 검증된 패턴: **마감임박/마일스톤(사회적 증거), UTM 캡처,
링크공유 추천 인센티브(네이버페이), 개인정보·마케팅 동의 분리, 기존 접수 조회.**

## 3. 기술 스택 / 산출물

```
프론트엔드 : HTML5, CSS3(반응형), Vanilla JS (의뢰 요구 스택 준수)
백엔드     : Node.js (Express), MySQL 8
배포       : 의뢰인 도메인 + HTTPS(SSL), (협의) 클라우드 또는 의뢰인 서버
산출물     : 소스 전체 + DB 스키마 + 관리자 계정 + 운영 매뉴얼 + 1개월 하자보수
```

## 4. 동봉 프로토타입 실행법

```
1) deliverables/resortpeople-leaflet 폴더에서 정적 서버 실행
     python3 -m http.server 8080
2) 모바일 랜딩      : http://localhost:8080/index.html?branch=mapo
   (상단 셀렉터로 9개 지점 전환, 폼 제출 → 리드 저장)
3) 관리자 컨셉      : http://localhost:8080/admin.html
   (권한을 '본사/지점'으로 바꾸면 열람 범위·편집권한이 달라짐)
4) 백엔드 청사진    : server/schema.sql (MySQL 스키마), server/app.js (Express 라우트)
```

> 프로토타입은 서버 없이 동작하도록 리드를 브라우저에 임시 저장합니다.
> 실서비스에서는 `js/app.js`의 `submitLead()` 주석된 `fetch("/api/leads")`로 전환됩니다.
